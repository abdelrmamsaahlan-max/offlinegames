# Pocket Party (Godot)

Offline 1–4 player mini-game collection prototype built with Godot 4.

## Open the project
1. Download or clone this repository.
2. Open Godot Project Manager.
3. Click **Import** and select `project.godot`.
4. Run the project with **F6/F5**.

## Current prototype
- Arcade-style menu
- Six mini-game prototypes
- 1–4 player setup
- Tournament rounds and score tracking

## Important status
This is a development prototype and has not yet been runtime-validated in Godot on a real device. Ads, Google Play Billing / VIP, final Android export configuration, and release compliance are not implemented yet.
